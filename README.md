# SajiPlan

Progressive Web App (PWA) untuk **perencanaan menu makan mingguan** dan pembuatan **daftar belanja otomatis**. Dibangun dengan HTML/CSS/JavaScript murni (tanpa framework), installable, dan bisa berjalan offline.

## ✨ Fitur
- Susun menu makan per hari dalam seminggu
- Generate daftar belanja otomatis dari menu yang dipilih
- PWA: installable + dukungan offline (service worker)

## 🛠️ Tech Stack
- Vanilla JavaScript, HTML5, CSS3
- Service Worker + Web App Manifest (PWA)
- Deploy: Netlify (`netlify.toml`)

## 🚀 Menjalankan
Buka `index.html` langsung di browser, atau jalankan server statis:
```bash
npx serve .
```

## 📄 Lisensi
Dibuat untuk keperluan pembelajaran.
